# 砚OS · YanOS

> 类型：互动体验

一个以东方水墨为语言的操作系统界面模拟：桌面是程序生成的水墨山水长卷（幅幅孤本），窗口是卷轴，Dock 是笔山，顶栏是绫边，时钟以十二时辰报时。昼为宣纸、夜为夜墨，内置文卷、记事（支持竖排）、墨画（带飞白笔触感）、算筹（中文数字）、终端、时晷、设置等应用。

## 设计

不模仿 macOS / Windows / Ubuntu，自创一套「文房」隐喻：

| 系统概念 | 砚OS 对应 |
|----------|-----------|
| 桌面壁纸 | 生成式水墨山水（Canvas，种子随机，可右键另起一幅） |
| 窗口 | 卷轴：展开动画、可拖拽、可铺满、可收起 |
| Dock | 笔山：器物列于案头，悬停出竖排题名 |
| 顶栏 | 绫边：左侧朱印，右侧十二时辰时钟 |
| 主题 | 昼 = 宣纸，夜 = 夜墨（星空、月、剪影山） |
| 任务栏 | 绫边中央的卷签（tab） |

## 应用

- **文卷**：虚拟文件系统，词笺、画谱等，双击以记事打开
- **记事**：可切换竖排（`writing-mode: vertical-rl`），自动存入 localStorage
- **墨画**：Canvas 毛笔，行笔越快墨越枯（飞白），五色墨 + 钤印 + 导出 PNG
- **算筹**：中文数字按键，结果同步转中文数字（如「三万零八十」）
- **端**：中文命令行（帮助 / 览卷 / 诗 / 时辰 / 昼夜 / 涤砚 / 关于）
- **时晷**：SVG 十二时辰日晷，指针实时转动
- **设**：昼夜切换、山间云雾开关、另起山水
- **关于**：设计说明

## 技术栈

- 纯单文件 HTML + CSS + 原生 JS，无外部依赖，可离线打开
- 生成式山水：值噪声山脊线 + 干笔皴擦 + 云雾渐变 + 纸纹颗粒
- 窗口管理器：z-index 焦点、拖拽、最小化/最大化、任务栏同步

## 使用方式

直接在浏览器中打开 `index.html` 即可。右键桌面可唤出菜单（另起山水 / 昼夜切换 / 关于）。
