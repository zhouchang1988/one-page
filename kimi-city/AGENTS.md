# 云端都市 (Kimi City)

> 类型：互动体验

基于 Canvas 的交互式城市体验，支持拖拽和滚轮缩放视角，呈现赛博朋克风格的都市夜景。

## 技术栈

- 纯 HTML/CSS/JavaScript
- Canvas 2D 绘制
- 触控和鼠标交互

## 使用方式

直接在浏览器中打开 `index.html` 即可。

## 其他页面

- `index2.html`：御剑飞行 · 月出云海 —— 基于 Three.js（CDN 加载）的 3D 仙侠飞行体验。月夜云海场景：三叠远山、浮空仙岛、宝塔灯火、仙鹤剪影与流萤光尘；支持自动巡航 / 手动御剑双模式（W/S 俯仰、A/D 转向、Space 加速、滚轮调速、C 切换、R 复位）。
